## 数据位置和来源规则

- `dataset/benchmark_complete` 保存权威原始 Solidity/Vyper 代码及明确标名的高层反编译代码；`dataset/benchmark_simplified` 保存原文连续切片和必要的未改写反编译输出。
- 所有原始源码直接下载自 Sourcify 等权威验证站点；源文件逐字来自对应原始响应，保留原名、编译配置、ABI、URL、时间和 SHA-256。官方复盘作为背景，与原始代码资格分别处理。
- 原始响应、运行码、纯反汇编、HTML、元数据、说明、编译配置及核验脚本都在 `dataset_artifacts`，不会进入源码目录。
- 反编译结果不是原始源码。公开在线工具的输入、原始输出、历史块、字节码散列、未报告版本及恢复错误单独记录；未执行本地反编译程序或下载合约。
- 四个新事件在完整/精简目录和中英文 CSV 对齐；两个 CSV 的旧字节完整保留，只按日期和案例ID追加。Allbridge 重新核查核心30原文件并复用旧记录，不再新增 CSV 行。
