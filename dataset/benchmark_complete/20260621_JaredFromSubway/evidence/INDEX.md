# JaredFromSubway 证据目录

已保存受害机器人的历史运行时字节码，原始 Solidity 和反编译代码尚未取得。原有报告索引与新增的原始 RPC 响应分开保留；新增材料的位置见 [字节码元数据](../bytecode.json)。

- [地址角色](address_roles.json)：受害 bot、恶意 wrapper、攻击者及批量执行合约分开记录。
- [来源检索记录与缺口](source_search.json)：记录实际尝试、被拒绝的下载和本地已有固定版本索引；不能把访问失败当作源码不存在。
- [完整报告事实索引](claims.json)：所有历史细节仍属报告证据，未重放链上交易。
- [中文说明](../../../../docs/cases/20260621_JaredFromSubway.md)：用途、授权账本、攻击过程、金额差异。
